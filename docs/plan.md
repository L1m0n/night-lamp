# Лампа — план реалізації

> Виконується по задачах, кожна закінчується перевіркою. Кроки — чекбокси `- [ ]`.

**Мета:** параметрична модель лампи (OpenSCAD → STL) і п'ять HTML-сторінок у стилі «Папір».

**Архітектура:** `case/lamp.scad` — єдине джерело геометрії; `tools/build.sh` ріже його на STL; `tools/stl2js.py` пакує STL у `assets/models.js`, яку читають обидві 3D-сторінки. Спільний стиль у `assets/paper.css`, спільна таблиця з'єднань у `assets/nets.js`: з неї малюються схема і монтаж, щоб піни не розійшлися.

**Стек:** OpenSCAD 2021+ (`/opt/homebrew/bin/openscad`), Python 3 stdlib, three.js 0.147.0 + OrbitControls (cdn.jsdelivr.net), Google Fonts (Newsreader, Inter), чистий HTML/SVG без збірки.

**Спека:** `docs/spec.md`

## Глобальні обмеження

- Стиль «Папір»: тло `#f7f4ee`, текст `#2b2722`, другорядний `#7b7266`/`#9a8f80`, лінії `#e4ddd1`, акцент `#c0643f`; темна: `#1d1b18` / `#ece6dc` / `#d9825e`. Заголовки Newsreader, текст Inter, `font-variant-numeric: tabular-nums`.
- Мова сторінок — українська.
- Профіль шейдера зі STEP: дно-кільце z=15 (r 40…55), заокруглення R25 з центром (55, 40) до r=80, пояс r=80 z 40…50, конус до r=70 на z≈249.7, стінка 2, верхня пластина z 244.69…246.69 з отвором Ø20, заглиблення під дімер r=67.5. Дімер Ø133×2.5 + хвостовик Ø18×10. Шайба Ø80.
- Зміни спеки: розріз на z=50, байонет 30°; лампа на 10 мм над столом; USB-C у боці шайби.
- 8 комірок 55×20×10 паралельно; колона-восьмигранник, грань 12.5; 8 смуг × 10 LED = 80; струм ≤ 1.5 А.
- Піни ESP32-C3: GPIO0 — повзунок, GPIO1 — дільник батареї, GPIO10 — дані стрічки, GPIO6 — P-MOSFET стрічки (V1), GPIO7 — KEY (V1).
- Стан чекбоксів — `localStorage` у try/catch; сторінка працює і без нього.
- Ширина 375 px без горизонтального скролу, відступ 16 px.

## На що дивитися при перевірці

1. Деталі стикуються: колона не впирається в пластину плафона, вал потенціометра доходить до хвостовика дімера, шасі проходить у чашу. → `assert` у `.scad` (задача 1).
2. Акумулятори «вітряком» не вилазять за внутрішню стінку чаші на своїй висоті. → `assert` у задачі 1.
3. Схема і монтаж показують ті самі піни для V1/V2. → обидві сторінки читають `assets/nets.js` (задачі 5–6).
4. `localStorage` недоступний (приватне вікно) — таблиця все одно працює, просто не пам'ятає. → крок у задачі 3.
5. Темна тема і ширина 375 px на всіх п'яти сторінках. → задача 7.

### Задача 1: Модель `case/lamp.scad` і STL

**Файли:** створити `case/lamp.scad`, `tools/build.sh`; вихід `case/stl/*.stl`.

**Інтерфейси:**
- Дає: `part` ∈ {`shade_top`, `bowl`, `puck`, `puck_core`, `chassis`, `reflector`, `column`, `knob_v1_carriage`, `knob_v1_guide`, `knob_v2_cap`, `dimmer`, `assembly`}. Кожна деталь в осі лампи (z=0 — стіл), щоб збірка складалась без зсувів. Окремо `variant` ∈ {1, 2} для `assembly`.
- Дає: `case/stl/<part>.stl` для кожної деталі, крім `assembly`; плюс `case/stl/batteries.stl`, `pcb.stl`, `pot_v1.stl`, `pot_v2.stl` як макети покупних деталей (для рендера, не друкуються).

- [ ] Профіль шейдера `shade_profile()` з точок Глобальних обмежень (`rotate_extrude` полігону + `offset` на стінку 2). Розріз: `bowl` = z<50, `shade_top` = z≥50, на стику 6 мм напуск зі сходинкою.
- [ ] Байонет: 3 ламелі 8×2 мм на `shade_top`, Г-подібні пази на `bowl` з поворотом 30° і фіксацією-горбиком 0.4 мм.
- [ ] `puck`: Ø80, висота 20 (z 0…20 після підйому, низ шейдера на z=10); кишеня під IP5306 (`ip5306 = [21, 25, 1.2]` — заміряти) з гніздом USB-C на висоті 5 мм у боці; вертикальний канал Ø8 під дроти. `puck_core` — вкладиш-сердечник у форму під цю кишеню.
- [ ] `chassis`: диск на комірі; «вітряк» 2 × 4 комірки (зовнішній квадрат 75×75, центр 35×35 під колону); гнізда ESP32 (`esp = [22.5, 18, 1.2]`) і перехідника (`perf = [30, 40]`); посадка колони — 8-гранний стакан глибиною 8. `reflector` — білий диск Ø150×1.2 з отвором під колону.
- [ ] `column`: восьмигранник, грань 12.5, висота від шасі до z=230; порожнина Ø22; пази на торцях під дроти; зверху посадка вузла дімера.
- [ ] `knob_v2_cap`: кришка колони з отвором Ø7.2 під втулку RK097 і гайку, верх втулки на z≈236. `knob_v1_guide` + `knob_v1_carriage`: каретка з B100K ходить 1.0 мм у напрямних, під нею гніздо KFC-003A (`sb = [6.1, 3.6, 2.5]`).
- [ ] `dimmer`: диск зі STEP, отвір хвостовика під рифлений вал Ø6 (`shaft_d = 6.0`, натяг 0.1, заміряти).
- [ ] `assert`-и: (а) радіус вітряка (53) + 1 < внутрішній радіус чаші на висоті верхнього шару; (б) верх колони + вузол < 244.69 − 0.5; (в) вал доходить у хвостовик ≥ 6 мм; (г) шасі ≤ внутрішнього Ø чаші на z=27. Повідомлення українською.
- [ ] `tools/build.sh`: цикл по деталях `openscad -o case/stl/$p.stl -D part=\"$p\" case/lamp.scad`, падає на першій помилці.
- [ ] Перевірка: `bash tools/build.sh` закінчується без `ERROR`/`Assertion`; кожен STL > 1 КБ; `openscad -D 'part="assembly"' -o /tmp/a.png --render case/lamp.scad` дає картинку, яку я переглядаю очима (розріз — `part="section"`).

### Задача 2: Пакування моделей `tools/stl2js.py` → `assets/models.js`

**Інтерфейси:**
- Дає: `window.LAMP_MODELS = { <name>: {pos: "<base64 Float32>", tri: <int>} }`, позиції в мм, нормалі рахує three.js. Порядок і назви — як у файлах `case/stl/`.

- [ ] Читає бінарний і текстовий STL (stdlib, `struct`), зварює вершини з округленням до 0.01 мм.
- [ ] Самоперевірка в кінці скрипта: для кожної моделі `tri` дорівнює кількості трикутників у STL, а розмір бокса до/після збігається з точністю 0.02 мм — `assert`.
- [ ] Перевірка: `python3 -I tools/stl2js.py case/stl assets/models.js` пише файл < 6 МБ і друкує таблицю «модель — трикутники — бокс».
